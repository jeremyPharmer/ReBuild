# AGENTS.md

## Project overview

ReBuild is a recovery app with incentives, built as a single Next.js 16 (App
Router) application. Users create a profile, check in daily to earn points and
build a streak, and redeem points for rewards. There is one service: the Next.js
app (frontend + API routes in the same process). See `README.md` for the tech
stack and the full list of scripts.

## Cursor Cloud specific instructions

- Single service: `npm run dev` serves both the UI and the API routes on
  `http://localhost:3000`. There is no separate backend to start and no database
  to provision.
- `npm run typecheck` (`tsc --noEmit`) fails with `Cannot find name 'LayoutProps'`
  (and similar route-type errors) on a clean checkout, because those globals are
  generated by Next into `.next/types`. Run `npm run build` (or start `npm run dev`)
  once first to generate them, then `typecheck` passes. `npm run build` already
  runs its own type check internally.
- Data is persisted to a file-backed store at `.data/db.json` (gitignored). To
  reset all users/state, delete that file. It is created lazily on first write.
- The current user id is stored in the browser under `localStorage["rebuild:userId"]`.
  The "Sign out" button clears it; there is no auth. To test onboarding again,
  sign out (or clear localStorage).
- Check-in is limited to once per calendar day (UTC). A second check-in the same
  day returns HTTP 409 by design — to re-demo the check-in reward, create a fresh
  user.
